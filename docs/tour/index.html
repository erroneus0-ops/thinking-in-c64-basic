A real Commodore 64, in your browser

This is a full C64, the 1982 home computer, running inside a web page. When you see READY. and a blinking square, it’s waiting for you.

Ten quick slides show you everything you need. Use the arrows, your keyboard’s arrow keys, or swipe.

Click, then type. Caps Lock off.

Click the C64 screen first, so your typing goes to the C64.

Type in ordinary small letters: the C64 shows them as capitals. Typing real capitals, with Shift or Caps Lock, gives graphics symbols instead. That’s the strange line here, and why it ended in an error.

Nothing happens until you press RETURN

Think of the screen as a web form. Each line is sent to the C64 only when you press RETURN (Enter on your keyboard). In the book, a ↵ at the end of a line means: press it.

A line with a number in front is stored for later. RUN carries it out.

Errors are normal

When the C64 doesn’t understand, it says so: ?SYNTAX ERROR. Here, the name GOLD hides the word GO, which the C64 has claimed for itself. Changing it to GLD fixed it.

Every C64 programmer meets errors all the time. Each one is a clue.

The special keys

Esc is RUN/STOP: it stops a running program.
Shift + Home clears the screen (on many laptops, Home is Fn + ←).
Page Up is RESTORE.

Prefer clicking? The same keys are buttons beside the C64.

Shift-click to move the cursor

Hold Shift and click anywhere on the C64 screen, and the cursor jumps there. Here it landed on the I of PIRNT, ready to fix the typo by typing over it.

It works while you’re typing commands. While a program runs, it waits.

Save your work with Submit

Submit program saves the program in the C64’s memory as a new version. Earlier versions are kept, so nothing is ever lost.

Run brings any version back and runs it. Listing shows it as text.

On a phone or tablet

Phones can’t show their own keyboard for the C64, so tap Show keyboard under the screen for a real C64 keyboard to tap on.

Reading and running work great on a phone. For writing longer programs, a computer is easier.

Chapter work: exercises, quiz, notes

Each chapter has exercises, a five-question quiz, and space for your notes: what was confusing, what was boring, what was fun. Everything is saved as you go.

Take a quiz as many times as you like. Every attempt is kept, so you can watch your scores climb.

A discovery, not a failure

Every mistake you make on the C64 teaches you something about how it works.

You don’t need to remember all of this. Come back to this tour whenever you like.
