About this reference

This volume documents Commodore 64 BASIC V2 completely, in standard terminology: every keyword, operator, reserved variable and error message. It is a companion to Thinking in C64 BASIC.

Verification. Every example and every stated output in this volume was produced on an emulated C64 running the original Commodore ROMs (BASIC V2, KERNAL 901227-03), and is reproduced exactly as the C64 displays it, including the two spaces before ERROR in error messages.

Coverage. The keyword index lists all 76 tokens of BASIC V2 plus π. Entries for individual keywords are added in families; the index shows the full scope from the start.

Conventions

Notation Meaning
KEYWORD Typed exactly as shown (on the C64 keyboard, unshifted letters appear as capitals).
expression Any valid expression of the stated type: numeric expression, string expression.
[ ... ] Optional part.
{ A | B } Exactly one of the alternatives.
... The preceding item may be repeated.
L ⇧I An abbreviation: type L, then hold SHIFT and type I.

Terminology

Term Meaning in this volume
Keyword A word reserved by BASIC V2. The interpreter recognizes keywords anywhere outside quotation marks, including inside variable names.
Token The single byte ($80–$CB, and $FF for π) that replaces a keyword when a line is stored. LIST converts tokens back into keywords.
Statement An instruction that performs an action, such as PRINT or GOTO. A line contains one or more statements separated by colons.
Function A keyword that returns a value computed from its argument(s), such as LEN or MID$. A function cannot stand alone as a statement.
Operator A symbol or keyword that combines values: arithmetic, relational or logical.
Expression A combination of constants, variables, functions and operators that evaluates to a single value.
Numeric variable Floating point: 5 bytes per value, about 9 significant digits. Name has no suffix.
Integer variable Signed 16-bit integer, −32768 to 32767. Name ends in %. Arithmetic on integers is performed in floating point.
String variable Up to 255 characters. Name ends in $.
Variable name Begins with a letter; may contain letters and digits; only the first two characters are significant.
Direct mode A line entered without a line number is executed immediately.
Program mode A line entered with a line number (0–63999) is stored as part of the program.
Logical line Up to two physical screen rows (80 characters) that the screen editor treats as one line. A line is entered by pressing RETURN with the cursor anywhere on it.

Abbreviations

Most keywords can be entered in an abbreviated form: one or more leading letters typed normally, followed by the next letter typed with SHIFT. The interpreter stores the abbreviation as the full keyword’s token, so it saves typing but not memory, and LIST always shows the keyword in full.

The rules, verified by entering each abbreviation:

  • The shifted letter can never be a keyword’s last character. In the keyword table, the final character of each keyword has its high bit set, as a shifted letter does, so a shifted final letter matches as an ordinary character and the keyword is not recognized. This is why IF, ON, OR, TO, FN, REM, NEW and INT have no abbreviation.
  • Keywords are tried in token order, and the first match wins. A shorter abbreviation may already belong to an earlier keyword: L ⇧E is LET (token $88), so LEN (token $C3) cannot use it; C ⇧O is CONT, not COS; L ⇧O is LOAD, not LOG; P ⇧O is POKE, not POS; T ⇧A is TAB(, not TAN.
  • PRINT has no abbreviation in this sense; instead, ? is accepted in place of the whole word and stored as the PRINT token.
  • INPUT and GO have none.

Of the 76 keywords, 52 have an abbreviation; each is listed in the index above.

An abbreviated line that would LIST longer than 80 characters can be stored but cannot be edited after listing, because the screen editor reads at most one 80-character logical line.

Reserved variables and constants

Name Value Notes

Strings

Functions that measure, extract, convert and build strings. Positions within a string are numbered from 1. Numeric arguments are truncated to whole numbers before use (2.9 is used as 2).

LEN

Token $C3 (195) · Kind Numeric function · Abbreviation none · Taught in Chapter 4

LEN(string)

Returns a number.

Argument Type Meaning
string string expression The string to measure.

Returns the number of characters in the string, from 0 (empty string) to 255. Spaces and control characters count.

Example

N$ : sample source string (26 letters)
L  : receives the length
N$ = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
L = LEN(N$)
PRINT L
 26

Edge cases

Expression Result Note
LEN(N$) 26
LEN("") 0 The empty string.
LEN(STR$(42)) 3 STR$ includes a leading space for positive numbers.

Related LEFT$, RIGHT$, MID$, STR$

LEFT$

Token $C8 (200) · Kind String function · Abbreviation LE ⇧F · Taught in Chapter 4

LEFT$(string, count)

Returns a string.

Argument Type Meaning
string string expression The source string.
count numeric expression, 0–255 Number of characters to take from the left end.

Returns the leftmost count characters of the string. If count is greater than the string’s length, the whole string is returned.

Example

N$ : sample source string (26 letters)
A$ : receives the result
N$ = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
A$ = LEFT$(N$,3)
PRINT A$
ABC

Edge cases

Expression Result Note
LEFT$(N$,3) "ABC"
LEFT$(N$,0) "" Empty string.
LEFT$(N$,30) "ABCDEFGHIJKLMNOPQRSTUVWXYZ" More than the length: the whole string, no error.
LEFT$(N$,2.9) "AB" Count is truncated.
LEFT$(N$,-1) ?ILLEGAL QUANTITY ERROR
LEFT$(N$,256) ?ILLEGAL QUANTITY ERROR

Errors ?ILLEGAL QUANTITY ERROR: count less than 0 or greater than 255.

MID$

Token $CA (202) · Kind String function · Abbreviation M ⇧I · Taught in Chapter 4

MID$(string, start[, length])

Returns a string.

Argument Type Meaning
string string expression The source string.
start numeric expression, 1–255 Position of the first character to take; the first character is position 1.
length numeric expression, 0–255 (optional) Number of characters to take. If omitted, all characters from start to the end.

Returns length characters of the string, beginning at position start. If fewer characters remain than requested, returns those that remain; if start is beyond the end, returns an empty string. Can replace LEFT$ (start 1) and RIGHT$, though those state the intent more directly.

Example

N$ : sample source string (26 letters)
A$ : receives the result
N$ = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
A$ = MID$(N$,3,4)
PRINT A$
CDEF

Edge cases

Expression Result Note
MID$(N$,3,4) "CDEF"
MID$(N$,24) "XYZ" Length omitted: to the end.
MID$(N$,25,10) "YZ" Fewer remain than requested: those that remain.
MID$(N$,27) "" Start beyond the end: empty string, no error.
MID$(N$,3,0) "" Length 0: empty string.
MID$(N$,2.9,2) "BC" Start is truncated to 2.
MID$(N$,0,1) ?ILLEGAL QUANTITY ERROR Positions start at 1.
MID$(N$,256) ?ILLEGAL QUANTITY ERROR
MID$(N$,3,256) ?ILLEGAL QUANTITY ERROR

Errors ?ILLEGAL QUANTITY ERROR: start less than 1 or greater than 255, or length less than 0 or greater than 255.

STR$

Token $C4 (196) · Kind String function · Abbreviation ST ⇧R · Taught in Chapter 4

STR$(number)

Returns a string.

Argument Type Meaning
number numeric expression The value to convert.

Returns the number as a string, formatted exactly as PRINT would display it, including the leading space that PRINT reserves for the sign of a positive number (or the minus sign of a negative one). No trailing space is added.

Example

S  : a numeric value
A$ : receives the result
S = 42
A$ = "SCORE:" + STR$(S)
PRINT A$
SCORE: 42

Edge cases

Expression Result Note
STR$(5) " 5" Leading space for a positive number.
STR$(-5) "-5" The minus sign takes that position.
STR$(0) " 0"
STR$(.5) " .5" No leading zero before the decimal point.
STR$(1/3) " .333333333" Nine significant digits.
STR$(1E10) " 1E+10" Large values in exponent form.

Related VAL, LEN

VAL

Token $C5 (197) · Kind Numeric function · Abbreviation V ⇧A · Taught in Chapter 4

VAL(string)

Returns a number.

Argument Type Meaning
string string expression Text to read as a number.

Returns the numeric value of the leading part of the string. Leading spaces are skipped; reading stops at the first character that cannot continue a number. A string with no leading number gives 0, without an error. Exponent notation (1E3) is accepted.

Example

A$ : text containing digits
V  : receives the value
A$ = "123"
V = VAL(A$) + 1
PRINT V
 124

Edge cases

Expression Result Note
VAL("12ABC") 12 Stops at the first non-numeric character.
VAL(" 12") 12 Leading spaces are skipped.
VAL("-3.5") -3.5
VAL("+5") 5
VAL("1E3") 1000 Exponent notation.
VAL("1,000") 1 A comma ends the number.
VAL("ABC") 0 No leading number: 0, no error.
VAL("") 0

Related STR$, ASC

CHR$

Token $C7 (199) · Kind String function · Abbreviation C ⇧H · Taught in —

CHR$(code)

Returns a string.

Argument Type Meaning
code numeric expression, 0–255 A PETSCII character code.

Returns a one-character string containing the character with the given PETSCII code. Codes include printable characters and control codes; for example, CHR$(147) clears the screen when printed, and CHR$(13) is RETURN.

Example

A$ : receives the character
A$ = CHR$(65)
PRINT A$
A

Edge cases

Expression Result Note
CHR$(65) "A"
CHR$(65.9) "A" Code is truncated.
ASC(CHR$(13)) 13 CHR$ and ASC are inverses.
CHR$(256) ?ILLEGAL QUANTITY ERROR
CHR$(-1) ?ILLEGAL QUANTITY ERROR

Errors ?ILLEGAL QUANTITY ERROR: code less than 0 or greater than 255.

Returns the PETSCII code (0–255) of the first character of the string.

Emulation notes

This chapter records verified facts about running BASIC V2 under emulation, with their sources, as a basis for comparing other and later emulators.

The course site (vc64web)

The course site embeds vc64web, a browser build of the VirtualC64 emulator, pinned to a fixed version. vc64web maps no PC key to several C64 keys; the course site adds these mappings:

C64 key PC key on the course site
RUN/STOP Esc
RESTORE Page Up
CLR/HOME Home (often Fn + Left Arrow on laptops)
SHIFT + CLR/HOME (clear screen) Shift + Home
SHIFT + INST/DEL (insert) Insert, or Shift + Backspace (vc64web otherwise ignores Shift on Backspace and deletes)
↑ (power) ^ (Shift + 6 on most layouts)

Shift-click on the C64 screen moves the cursor by feeding cursor-key codes through the KERNAL keyboard buffer, only while BASIC is in direct mode, waiting for input, and not in quote or insert mode. This is a feature of the course site, not of the C64.

ROM files

An emulated C64 requires copies of the original ROMs, which remain under copyright and are not distributed with the course site. The course site’s setup copies them from a local VICE installation.

File Size Contents
basic.rom 8192 bytes BASIC V2 interpreter
kernal.rom 8192 bytes KERNAL operating system
chargen.rom 4096 bytes Character generator (the C64’s font). The standard ROM (901225-01) begins with the bytes 3C 66 6E; a Japanese character ROM (906143-02) differs and must not be used.
dos1541.rom 16384 bytes 1541 disk drive firmware, required for disk images
