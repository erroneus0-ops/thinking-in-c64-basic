Variables, as the C64 knows them

Submit

Saves the program now in the C64’s memory as a new version. Earlier versions are kept.

Saved versions

Run puts a version back and runs it. Load puts it back so you can keep editing, then Submit again. Listing just shows it. Run and Load replace what’s in the C64 now, so submit first if you want to keep it.

    Special keys
    
    
    
      
      
      
    
    
    
    On your keyboard: Esc is RUN/STOP, Page Up is RESTORE, Home is CLR/HOME, and Shift + Home clears the screen (on many laptops, Home is Fn + Left Arrow). The Clear screen button sits under the C64 screen. RUN/STOP stops a running program. RUN/STOP + RESTORE also tidies the screen and colors, and keeps your program. Show keyboard, under the C64 screen, brings up a C64 keyboard you can tap, for phones and touch screens.
    

    
    The C64 itself
    
    
    
    
    Click the C64 screen before typing, and keep Caps Lock off. Shift-click on the screen moves the cursor there while you type commands. Reset clears the program from memory, so submit first.
